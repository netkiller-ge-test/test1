# 2026년 영업팀 통합 운영 가이드

## 1. 고객 등급 및 할인 정책
- **Standard**: 기본 요금 적용 (할인 없음)
- **VIP**: 10% 자동 할인 적용 (연간 계약액 5천만원 이상)
- **Enterprise**: 별도 협의 (최대 20% 할인 + 전담 엔지니어 배정)

## 2. 프로모션 코드 정책
- 2026년 4분기 특별 프로모션 코드: `VINA2026` (신규 계약 시 5% 추가 할인)

## 3. 장애 및 문의 접수 절차
- 고객사 기술 이슈 발생 시 GitHub Issues 게시판에 `[긴급]` 태그를 달아 등록할 것.
- 24시간 이내 담당 개발자 미지정 시 영업 담당자가 기술팀에 즉시 스컬레이션 수행.
